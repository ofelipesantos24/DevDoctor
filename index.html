Sua API falhou. Descubra por quê.

O DevDoctor testa o endpoint, aponta o problema, a causa provável e o que fazer a seguir. Roda no seu terminal, sem conta e sem plataforma paga.

npm install && npm run build
$ devdoctor check https://api.exemplo.com/users GET /users → 500 · 1840 ms · 412 B ✖ ERRO Erro interno do servidor (500) Causa: exceção não tratada no servidor. 1. Veja os logs no horário da requisição. 2. Reproduza com o mesmo payload localmente. ▲ AVISO Resposta lenta: 1840 ms ▲ AVISO Possível stack trace exposto ✔ OK JSON válido

O que ele verifica

Diagnóstico automático
Erros HTTP, timeouts, conexão recusada, DNS e certificados HTTPS inválidos.
Teste de endpoints
Status, tempo de resposta, JSON válido e status esperado.
Segurança básica
CORS mal configurado, stack traces e credenciais na resposta, cabeçalhos que revelam tecnologia. Análise passiva: nenhum ataque é realizado.
Relatório compartilhável
Texto no terminal, JSON para automação ou HTML autônomo para enviar à equipe.

Comece em um minuto

git clone https://github.com/seu-usuario/devdoctor.git
cd devdoctor && npm install && npm run build

node dist/cli.js check https://api.exemplo.com/users
node dist/cli.js check https://api.exemplo.com/users --origin http://localhost:5173
node dist/cli.js check https://api.exemplo.com/users --format json -o relatorio.json
node dist/cli.js run   # vários endpoints a partir de devdoctor.config.json

Retorna código de saída 1 quando encontra erros, então funciona também no CI. Detalhes de todas as opções estão no README.
